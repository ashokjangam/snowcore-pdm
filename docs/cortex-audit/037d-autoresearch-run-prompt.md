# Cortex prompt 037d — run bounded 25-trial campaign

Use connection `hackathon`. Do not edit files.

```sql
USE ROLE ACCOUNTADMIN;
USE DATABASE SNOWCORE_REAL;
USE WAREHOUSE COMPUTE_WH;
ALTER SESSION SET STATEMENT_TIMEOUT_IN_SECONDS = 2400;
CALL SNOWCORE_REAL.ML.RUN_PIADE_AUTORESEARCH(25);
```

Wait for the CALL to finish. Then report:

```sql
SELECT CAMPAIGN_ID, STATUS, EVALUATED_TRIALS, CRASHED_TRIALS,
       REJECTED_PROPOSALS, STOP_REASON, PROMOTION_STATUS,
       PROMOTION_ELIGIBLE, BASELINE_MEAN_AUC, CHAMPION_MEAN_AUC,
       HOLDOUT_EVALUATED, PRODUCTION_TABLES_MODIFIED, REGISTRY_STATUS
FROM SNOWCORE_REAL.ML.PIADE_RESEARCH_CAMPAIGN
ORDER BY STARTED_AT DESC LIMIT 1;

SELECT GATE_ORDER, GATE_NAME, PASSED, DETAIL
FROM SNOWCORE_REAL.ML.PIADE_RESEARCH_PROMOTION_GATE
WHERE CAMPAIGN_ID = (
  SELECT CAMPAIGN_ID FROM SNOWCORE_REAL.ML.PIADE_RESEARCH_CAMPAIGN
  ORDER BY STARTED_AT DESC LIMIT 1)
ORDER BY GATE_ORDER;

SELECT COUNT(*) HOLDOUT_ROWS_WRITTEN,
       COUNT_IF(USED_FOR_SELECTION) HOLDOUT_USED_FOR_SELECTION
FROM SNOWCORE_REAL.ML.PIADE_RESEARCH_HOLDOUT_METRIC
WHERE CAMPAIGN_ID = (
  SELECT CAMPAIGN_ID FROM SNOWCORE_REAL.ML.PIADE_RESEARCH_CAMPAIGN
  ORDER BY STARTED_AT DESC LIMIT 1);
```

Do not ALTER production `PLANT_B_*` tables. If the CALL errors, return the
full error including `ML.PIADE_RESEARCH_CAMPAIGN.ERROR_MESSAGE`.
